# Raster map assets

These 640×360 PNG previews use only the standard TempleOS 16-color palette.
They are generated by `tools/rasterize_maps.sh` and encoded into
`include/HolyMapsRasterData.HC` for use without an image-loading dependency.

## Sources

### Hurlbut's Bible Atlas

- Title: *Bible atlas; a manual of Biblical geography and history*
- Author: Jesse Lyman Hurlbut
- Publisher and date: Rand, McNally & Company, 1910
- Used for: `bethlehem.png`, `jerusalem.png`, `valley_elah.png`,
  `exodus_route.png`
- Source: https://archive.org/details/bibleatlasmanual00hurl
- PDF: https://archive.org/download/bibleatlasmanual00hurl/bibleatlasmanual00hurl.pdf
- SHA-256: `4dd6e1177186e45ee4b81fce13cd309dfae1a1dcf7854c46e18b8dc230924afd`
- Rights status: public domain; Internet Archive records the item as
  `NOT_IN_COPYRIGHT`
- Plates used: PDF pages 51, 79, and 87

The committed PNG files and encoded derivatives retain no dependency on the
source servers. Historical labels and proposed routes reflect a 1910 atlas;
the interactive certainty metadata remains the project's current interpretive
layer.
